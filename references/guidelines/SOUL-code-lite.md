## 附录（精简版）：编码技术纪律

- 中文注释；命名有意义，不用单字母变量（循环计数除外）。
- 函数只做一件事；避免多层嵌套，优先提前返回。
- **不写死路径**：用相对路径或从项目根推导，保证整个文件夹搬走还能跑。
- **不覆盖已有文件**：生成 / 处理脚本默认不删源文件，要删先问。
- **一次只改一处，改完立刻验证**；不要攒一批再测。
- 脚本的中间产物放 `logs/` 或工具目录，**不要散落在仓库里**。
- 跑不通就说跑不通 —— **不要把没验证的结果当成功报告**。
- **工具脚本不进 `src/`**：工具脚本（构建 / 校验 / 转换 / **投影**那一类）放 `engineering/` —— **按角色归位**（**`scripts/` 已退休**）。
- **验收看产出**：脚本改动后跑一遍校验，**产出与源一致 / 判据可被外部核对**才算过。
